# KRISH CAPTURES

A minimalist fine-art photography portfolio built for GitHub Pages.

## Publish

1. In GitHub open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose **main** and **/(root)**, then **Save**.
4. Once deployed, open `https://9krish.github.io/krish-captures.-/`.

## Customize

- Open `index.html` in GitHub and select **Edit**.
- Find `const SITE=` in the JavaScript near the end of the file.
- Replace `Photographer Name`, `hello@example.com`, the sample biography, and `aboutImage`.
- Replace the sample Unsplash photo identifiers in `collections` with your dad's selected Lightroom photographs. For local image files, change the `photo()` helper and/or gallery data to use image paths under an `images/` folder (GitHub's upload-files interface works for JPEGs).
- Export appropriately sized JPEGs from Lightroom in the sRGB color space. Keep original-resolution photos out of this public repository.

## Important

All displayed photographs currently are third-party demonstration images; they are **not** Krish Captures work. The contact form opens the visitor's email application (mailto) rather than sending through a server. Set a real email before sharing the website with visitors.
